사이 — Homework3 메모 목업

실행
VS Code에서 Homework3를 열고 Live Server의 Go Live를 실행합니다.
현재 미리보기: http://127.0.0.1:5500/
별도 설치나 빌드 없이 index.html, style.css, sketch.js로 실행됩니다.

사용
1. 하단 입력창에 최대 280자 작성 후 Enter 또는 화살표로 전송합니다.
   Shift+Enter는 줄바꿈이며, 한글 조합 중 Enter는 전송하지 않습니다.
2. 처음에는 원래 문장 그대로 나타납니다.
3. 문장 주변에서 포인터를 움직이거나 손가락으로 쓸면 점진적으로 자모 패턴이 됩니다.
4. 패턴이 완성되면 보관됩니다. '주변을 쓸어 저장' 버튼은 키보드 사용자를 위한 대체 경로입니다.
5. 저장된 글자/패턴을 한 번 클릭하면 원문이 보이고, 다시 클릭하면 같은 패턴으로 돌아갑니다.
   별도의 원문 보기 버튼은 없으며 키보드 Enter/Space로도 전환할 수 있습니다.
   드래그나 두 손가락 패닝은 원문 전환으로 처리하지 않습니다.
6. 트랙패드 두 손가락 슬라이드로 가로/세로 이동합니다.
   터치 화면에서는 두 손가락 이동과 벌리기/오므리기로 확대·축소할 수 있습니다.
   트랙패드에서도 핀치 제스처로 캔버스를 확대·축소합니다.
   기본 배율은 65%이며 화면이 좁으면 더 작게 맞춥니다. 범위는 8~300%입니다.
   키보드에서는 캔버스 포커스 후 방향키로 이동, +/-로 확대·축소, 0으로 기본 배율로 돌아갑니다.
7. 왼쪽 아래 버튼으로 전체 메모 또는 최근 메모로 돌아갑니다.

시각 규칙
메모 하나 안에서 자모의 등장 횟수를 계산합니다.
같은 자모는 같은 크기와 굵기이며, 빈도가 높을수록 작고 가늘어집니다.
복합 모음과 겹받침도 구성 자모로 분해합니다. 된소리 자음은 보존합니다.
개별 자모 → 반복 패턴 → 작은 군집 → 비대칭 전체 형태의 계층으로 구성합니다.
작고 자주 나오는 자모는 시각적으로 추가 반복하여 질감 있는 면을 만듭니다.
추가 반복은 원문 내용을 변경하지 않으며 같은 자모의 크기·굵기를 유지합니다.
군집마다 짧은 행렬, 물결, S자, 원호, 고리, 사선 띠를 조합합니다.
고리의 안쪽과 큰 자모 주변에는 흰 여백을 남기며, 일부 문자 줄은 바깥으로 뻗습니다.
묶음의 위치와 순서는 빈도와 무관하게 무작위로 결정됩니다.
메모별 고정 시드를 사용하여 새로고침해도 같은 구성이 유지됩니다.
글자의 실제 획 너비/높이를 측정하여 회전 후 충돌을 검사합니다.
글줄 사이 추가 여백은 폰트 크기의 0~1.6배 범위에서 무작위로 정합니다.
0에 가까운 간격을 더 자주 선택하여 자모가 촘촘히 이어지도록 합니다.
다른 묶음은 기존 획 바로 옆에 연결되어 빈틈에 맞물립니다.
새 메모는 기존 메모 중 무작위로 하나를 선택해 그 근처의 비어 있는 위치에 놓입니다.
배치 방향도 무작위로 정하여 가로와 세로로 캔버스가 확장됩니다.
정상적으로 저장된 기존 메모의 위치는 유지합니다.

저장
이 브라우저의 localStorage('sai.homework3.v1')에 원문, 위치, 저장 상태와 실루엣 색상·표현을 보관합니다.
전환 전 문장도 복구를 위해 임시 보관하며 '기억' 개수에는 완성된 패턴만 포함됩니다.
같은 브라우저/주소에서 새로고침하면 복원됩니다. 서버나 다른 기기로 동기화하지 않습니다.
삭제한 메모는 원문·위치·자모·실루엣과 함께 저장 목록에서 제거됩니다.
원래 index.html 및 sketch.js는 backup-before-sai-* 폴더에 보관했습니다.

검증
verify.cjs: 한글/복합 자모 분해, 원래 자모 보존과 시각적 반복, 고정 시드 구성과 무작위 묶음 순서, 회전된 글자 충돌,
같은 자모 스타일 일치, 빈도에 따른 스타일, 겹침 없음, 최대 길이 입력을 검사합니다.
브라우저: 전송, 포인터 전환, 저장, 새 메모 배치, 가로/세로 패닝,
전체/최근 보기, 원문 복귀, 새로고침 복원, 좁은 화면 배치를 확인했습니다.

성능 개선
이동·핀치의 화면 갱신은 한 프레임당 한 번으로 모읍니다.
배율 표시가 같은 값이면 다시 쓰지 않습니다. 화면 크기는 창 크기가 바뀔 때만 측정합니다.
자모별 SVG 대신 메모당 하나의 SVG와 text 요소로 원래 좌표·크기·회전을 표현합니다.
화면 밖의 저장 메모는 DOM에서 잠시 제외하고 근처로 오면 기존 요소를 복원합니다.
입력 중인 메모, 현재 포커스되거나 터치 중인 메모는 유지합니다.
글자별 will-change를 제거하고 글자 크기 측정 결과를 재사용합니다.

축소 화면의 실루엣
실제 캔버스 배율이 15% 이하이면 저장된 메모의 자모 대신 실루엣을 표시합니다.
15%보다 확대하면 기존 자모 패턴이 그대로 나타납니다. 작성 중인 메모와 원문 보기 기능은 유지합니다.
메모별 시드로 채움·외곽선 중 하나를 정하고 다음 8색 중에서 색상을 선택합니다.
채움 또는 외곽선이 작성 순서로 3번 연속 나오면, 다음 메모는 반드시 반대 표현으로 정합니다.
표현은 메모 생성 시 정하고 함께 저장하므로 새로고침해도 연속 횟수와 표현이 유지됩니다.
새 메모는 바로 직전에 작성한 메모의 색상을 제외한 7색 중에서 선택합니다.
색상은 작성 시점에 정해 저장하므로, 패턴 전환 순서나 화면상의 위치와 무관합니다.
기존 메모는 작성 순서로 복원하며 연속해서 같은 색인 경우만 다른 색으로 조정합니다.
#2c7dff #7835da #ff99be #ff5d31 #ff9a3e #ccff66 #b19375 #4c292f
확대·축소 또는 새로고침으로 같은 메모의 색상과 표현이 바뀌지 않습니다.
반복 군집의 면을 합치고 가까운 군집을 연결해 기존 자모 구성의 외곽을 만듭니다.
외곽의 돌출된 꼭짓점에만 라운딩을 적용하고, 안으로 들어간 꼭짓점은 직선 접점을 유지합니다.
각 메모의 실루엣 경로를 한 번 생성해 재사용하며, 확대·이동 중에는 경로를 다시 계산하지 않습니다.
검증: 15% 경계의 레이어 전환, 원문/패턴 토글, 2가지 표현과 8색 전체 조합,
긴 문장·반복 문장에서도 군집 보존, 외곽 연결, 볼록한 곳만 라운딩, 기존 자모 좌표 보존을 확인합니다.

메모 위치 이동
마우스·펜·손가락으로 메모를 약 0.45초 누르면 테두리가 생기며 이동 상태가 됩니다.
그대로 끌어서 원하는 곳에 놓으면 메모 전체가 이동하고 위치가 저장됩니다.
자모·실루엣·원문 상태와 작성 중인 메모 모두 이동할 수 있습니다.
다른 메모와 겹쳐 놓아도 새로고침 후 그 위치를 그대로 복원합니다.
짧게 클릭하면 기존처럼 원문/패턴이 전환되고, 이동 뒤에는 클릭 전환이 발생하지 않습니다.
두 번째 손가락을 올리면 메모 이동을 마치고 캔버스 이동·확대로 이어집니다.
Esc 또는 제스처 취소 시 원래 위치로 돌아옵니다.
이동 중에는 한 메모의 화면 변환만 프레임당 한 번 갱신하고, 놓을 때 위치·캔버스 범위·저장을 갱신합니다.

GitHub 웹에서 열기
과제 모음 왼쪽의 Homework3 / 중간과제 / 새 창 열기 버튼으로 독립 화면을 엽니다.
직접 주소: https://zzzziruto.github.io/Homework_template/Homework3/
실행 파일은 index.html, style.css, sketch.js이며 별도 라이브러리 설치가 필요 없습니다.
로컬의 backup-before-* 폴더와 사용하지 않는 vendor 폴더는 이번 업로드에 포함하지 않습니다.
삭제는 같은 메모를 0.05초 이내 간격으로 두 번 클릭하거나 터치하면 실행합니다.

메모 삭제
같은 메모의 짧은 클릭/터치가 50ms 이내에 두 번 완료되면 삭제합니다.
간격은 sketch.js의 DELETE_TAP_INTERVAL에서 조정할 수 있습니다.
한 번 클릭하면 50ms 뒤 기존 원문/패턴 전환이 실행됩니다. 드래그·멀티터치·휠 이동은 삭제로 처리하지 않습니다.
실제 배율이 15%보다 크면 보이던 글자들이 벌어져 화면 밖으로 날아갑니다.
15% 이하이면 기존 실루엣 내부를 여러 크기의 원으로 분해해 화면 밖으로 보냅니다.
메모는 삭제 시작 시 저장 목록에서 제거하므로 효과 도중 새로고침해도 복원되지 않습니다.
저장소 갱신에 실패하면 삭제를 취소하고 메모를 유지합니다. 마지막 메모를 지우면 저장 키도 제거합니다.
한 개의 임시 캔버스와 애니메이션 루프를 공유하며 효과 종료 시 입자·캔버스·프레임 참조를 해제합니다.
삭제한 메모의 DOM·원문·자모·윤곽 참조와 진행 중인 전환 프레임을 정리하고 글자 측정 캐시도 비웁니다.
탭이 가려지거나 종료되면 임시 효과를 즉시 정리합니다. 동작 줄이기 설정에서는 이동 효과 없이 삭제합니다.
verify-deletion.cjs에서 50ms 경계, 단일 클릭 유지, 저장 실패 복구, 마지막 키 제거, 화면 밖 이동과 효과 정리를 검사합니다.
