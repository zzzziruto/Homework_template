# DanceTogether · GitHub Pages + p5.party

두 휴대폰/태블릿에서 **같은 GitHub Pages 주소**를 엽니다. 두 기기가 접속하면 자동으로 연결되고, 3초 카운트다운 후 DJ와 DANCER를 무작위로 한 명씩 배정합니다. 역할 화면을 2초간 표시한 다음 플레이합니다. 방 코드·초대 코드·역할 선택은 없습니다.

댄서는 **움직임 접근 허용**을 누르고 아이폰의 권한 요청에 **허용**을 누릅니다. 개발용 인증서나 프로파일 설치는 필요하지 않습니다. Python 서버를 켜둘 필요도 없습니다. 두 기기는 서로 다른 인터넷 연결을 사용할 수 있습니다.

## 사용 주소

기존 Homework_template 저장소의 GitHub Pages 설정을 그대로 사용합니다. 배포한 주소 끝에 `/DanceTogether/`를 붙여 엽니다.

컴퓨터에서 열면 참가자가 되지 않고 연결 상태만 표시합니다. 참가자는 휴대폰/태블릿 두 대입니다. 세 번째 기기는 기존 참가자가 나가야 접속할 수 있습니다.

## 기존에 유지한 기능

- 기존 DJ 이미지와 원판·패드·템포·볼륨의 터치 조작.
- 댄서가 흔들 때마다 100부터 1씩 감소하고, 두 화면의 숫자와 색 공유.
- 공통 카운트다운, 무작위 역할 배정, 완료 화면과 콩페티.
- 완료 후 한 번 더 실행하면 역할을 다시 배정.
- 같은 브라우저에서 새로고침해도 진행 상태 복구.
- 컴퓨터의 관찰 화면, 참가자 두 명 제한.
- 소리 없이 동작. 노래 제목은 기존 이미지의 일부이며 실제 음원 재생은 없습니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html`, `style.css`, `assets/` | 화면과 기존 이미지 |
| `app.js` | 화면·터치·움직임 입력 |
| `party-client.mjs` | p5.party 접속, 데이터 교환과 재접속 |
| `session.mjs` | 자동 참가, 역할·게임 진행 규칙 |
| `motion.mjs` | 버튼에서 센서 권한 요청, 실제 신호 확인 |
| `vendor/` | 예제와 같은 p5.party 0.16.0 및 MIT 라이선스 |
| `tests/` | 센서 권한·게임 상태 검증 |
| `start.command` | 컴퓨터에서 정적 화면을 확인하는 선택적 미리보기 |

이 버전은 `/api`나 `server.py`를 호출하지 않습니다. 예전 `data/`와 `.certificates/`는 읽거나 변경하지 않으며, Git에 추가하지 않습니다.

## 통신과 검증 범위

교수자 예제와 같은 `wss://demoserver.p5party.org`를 사용합니다. 화면은 GitHub Pages가 제공하고, 기기 간 데이터 공유는 p5.party가 담당합니다. p5.party가 정한 호스트 한 곳에서 게임 상태를 갱신하며, 조작 순번과 확인 응답으로 중복 반영을 막습니다. 호스트가 바뀌면 현재 상태를 이어받습니다.

p5.party 공개 데모 서버를 이용하는 수업용 프로토타입입니다. 서버 점검이나 네트워크 제한이 있으면 연결이 지연될 수 있습니다. 기기 식별용 임의 값과 게임 조작만 전송하고, 개인 정보나 인증서 키는 보내지 않습니다.

검증: `node --test DanceTogether/tests/*.test.mjs` (저장소 최상위에서 실행).
센서 권한, 유효 센서 신호, 자동 연결, 무작위 역할, 컴퓨터 비참여, 세 번째 기기 제한, 중복 움직임 방지, 컨트롤 검증, 완료·재시작·재접속 테스트 14개 통과. 실제 p5.party 서버를 통한 브라우저 두 화면의 자동 연결, 역할 배정, 숫자 공유, DJ 상태의 새로고침 복원과 세 번째 기기 제한을 확인했습니다.

아이폰의 실제 가속도 신호와 기기별 흔들기 감도는 휴대폰에서 최종 확인해야 합니다. 센서 신호가 없는 경우 감지 ON으로 표시하지 않고 오류를 안내합니다. 시연용 터치 버튼은 센서 검증을 대신하지 않습니다.

## 로컬 화면 미리보기 (선택)

VS Code에서 DanceTogether 폴더를 열어 Live Server로 확인하거나 `start.command`를 실행할 수 있습니다. 실제 아이폰 센서 테스트는 GitHub Pages의 HTTPS 주소에서 진행하세요.
