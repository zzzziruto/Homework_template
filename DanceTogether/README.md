# DanceTogether

늘 함께 야작하는 두 사람을 위한, 소리 없는 댄스 브레이크 웹앱입니다.

## 실행

이 폴더를 VS Code로 열고 터미널에서 실행하세요.

```sh
python3 server.py
```

Mac에서는 `start.command`를 실행해도 됩니다. Python 3.9 이상이며 별도 패키지 설치는 없습니다.

- 컴퓨터: http://localhost:8785
- 휴대폰: 서버 터미널에 표시되는 `http://컴퓨터IP:8785`
- 센서용 HTTPS: `https://컴퓨터IP:8786`

서버 터미널은 계속 켜두세요. 두 폰과 컴퓨터는 같은 Wi-Fi에 연결해야 합니다. 폰에서 localhost를 열면 컴퓨터에 접속되지 않습니다. 파일 더블클릭이나 VS Code Live Server만으로는 두 기기 데이터가 공유되지 않으므로 반드시 위 서버를 사용하세요.

접속 문제가 있었던 이전 버전처럼, 개발 도구가 실행한 서버의 네트워크 접근이 제한될 수 있습니다. 폰 시연은 맥의 일반 터미널 또는 VS Code 터미널에서 직접 실행해주세요.

## 동작 순서

1. 컴퓨터는 접속 상태를 보는 서버 화면만 표시하며 참가자로 등록되지 않습니다. 휴대폰·태블릿만 참가합니다.
2. 첫 모바일 기기는 친구를 기다립니다. 방 코드·초대·역할 선택이 없습니다.
3. 두 번째 모바일 기기가 연결되는 순간부터 서버의 공통 시각으로 3초를 셉니다.
4. 3초가 지나면 DJ와 DANCER를 무작위로 한 명씩 배정합니다.
5. 목업의 `You are... DJ! / DANCER!` 화면을 2초간 보여준 뒤 플레이를 시작합니다.
6. 댄서가 폰을 흔들면 100부터 한 번씩 줄고 색이 바뀝니다. DJ 중앙 숫자와 색도 함께 바뀝니다.
7. DJ는 두 원판, 패드, 템포와 볼륨 슬라이더를 터치·드래그합니다. 조작 상태는 서버에 공유됩니다.
8. 0에 도달하면 양쪽에 COMPLETE와 콩페티가 나타납니다.
9. 한 번 더를 누르면 다시 3초 후 역할을 배정합니다.

목업의 노래 이름은 그래픽의 일부이며 현재 버전에는 음원과 소리가 없습니다. ▶/Ⅱ 버튼은 원판 회전 표시만 전환합니다. 회전 여부가 보이도록 원판에 작은 표시선을 두었습니다. DJ는 가로 화면, 댄서는 세로 화면으로 쓰는 것이 좋습니다.

## 아이폰 실제 흔들기 감지

HTTP에서는 화면과 시연용 터치 버튼으로 데이터 공유를 확인할 수 있습니다. 실제 움직임 센서는 HTTPS와 사용자 권한 허용이 필요합니다.

로컬 시연을 위해 이 서버는 실행하는 컴퓨터 전용 개발 인증서를 생성합니다. 시스템 신뢰 설정을 자동으로 변경하지 않습니다.

1. 아이폰 Safari에서 컴퓨터의 HTTP 주소를 엽니다.
2. 화면 오른쪽 위 `?` → `두 폰 연결 · 움직임 설정`을 엽니다.
3. 개발용 인증서를 내려받습니다. 직접 주소는 `http://컴퓨터IP:8785/dance.cer`입니다.
4. 설정 → 일반 → VPN 및 기기 관리에서 **Yejis Dance Local** 프로파일을 설치합니다.
5. 설정 → 일반 → 정보 → 인증서 신뢰 설정에서 해당 인증서를 신뢰합니다.
6. 앱의 HTTPS 주소로 다시 열고, 댄서 화면의 `움직임 감지 켜기`를 눌러 권한을 허용합니다.

이전 프로토타입의 `Dance Together Local Development` 인증서와 다릅니다. 이번 폴더에서 생성한 인증서를 사용하세요. 테스트가 끝나면 설치한 개발용 프로파일을 제거할 수 있습니다. 인증서 경고가 나오면 우회해서 진행하지 말고 설치·신뢰 설정을 확인하세요.

다른 Wi-Fi로 바뀌면 서버를 재시작해서 새 IP가 인증서에 포함되게 하세요. 네트워크가 기기 간 통신을 막는 경우 동일한 개인 공유기/핫스팟을 사용하세요.

## 파일

- `index.html`: 화면 구조
- `style.css`: 목업 스타일과 조작 모션
- `app.js`: 폰 센서, 원판·패드·슬라이더, 화면 전환, 콩페티와 데이터 공유
- `server.py`: 두 기기 연결, 3초 역할 배정, 데이터 검증·보관, HTTP/HTTPS
- `assets/dj-original.png`: 제공한 Illustrator의 DJ 아트보드 렌더링
- `test_session.py`: 서버 상태와 역할·공유 로직 검증
- `.vscode/tasks.json`: VS Code의 기본 빌드 작업으로 서버 실행

실행하면 `data/session.json`과 `.certificates/`가 생성됩니다. 실제 기록과 개인 개발용 키이므로 다른 사람에게 공유하지 마세요. 서버는 HTML·JS·CSS·이미지와 인증서 공개 부분만 제공하며, 기록·키·서버 코드는 웹에서 내려받을 수 없습니다.

## 검증

```sh
python3 -B -m unittest -v test_session.py
```

3초 배정 시점, 한 명씩 역할 배정, 세 번째 접속 제한, 중복 움직임 방지, 역할별 쓰기 제한, 공동 조작 상태, 완료와 재시작, 재접속 후 복원을 확인하는 14개 테스트가 통과했습니다. 컴퓨터의 비참여와 모바일 기기 판별도 확인합니다. 브라우저에서 대기→역할→DJ 화면과 컨트롤 표시를 확인했습니다. 실제 휴대폰의 센서 감도는 기기에서 확인해주세요.

예약 알람, 소리 및 MP3 처리는 이번 구현 범위에 포함하지 않았습니다.
